# VoiceControlApp 🎙️

VoiceControlApp is a lightweight and intuitive Windows application designed to control your operating system using voice commands. It enhances accessibility and productivity by allowing you to execute actions hands-free.

## ✨ Features
- **Voice Commands:** Control your PC using your voice.
- **Easy Launch:** Comes as a standalone executable file, no complex installation needed.
- **Performance:** Lightweight background operation with minimal system resource usage.

## 🚀 How to Download and Run
1. Go to the **Releases** section on the right side of this GitHub page.
2. Download the latest version of `VoiceLauncher.exe`.
3. Locate the downloaded file on your computer.
4. Double-click `VoiceLauncher.exe` to run the application.

*Note: Windows SmartScreen might show a warning since the app is new and unsigned. Click "More info" and then "Run anyway" to open it.*

## 📋 System Requirements
- **OS:** Windows 10 / Windows 11
- **Hardware:** A working microphone connected to your PC.
- **Internet:** Connection may be required depending on the speech recognition engine used.
